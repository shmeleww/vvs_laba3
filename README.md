# vvs_laba3 
Блок-схема и код лабораторной работы №3 по основам программирования. 
Тема Одномерные массивы и методы 

## Как установить и запустить

1. Скачайте проект командой `git clone https://github.com/shmeleww/vvs_laba3/tree/main`;
2. Запустите проект в Visual Studio, открыв файл **`Laba3.slnx`**;
3. Нажмите зелёную кнопку `Пуск` на панели сверху.

## Как открыть блок-схему

1. Установите yEd Graph Editor;
2. Запустите файл **`Блок-схема лаба 3.graphml`**
